# Competition Packet Notes

Captured: 2026-07-28  
Source: organizer-linked Byte2Beat competition packet  
Purpose: local planning evidence, not an organizer ruling

The packet describes an open cardiovascular computational and machine-learning
challenge. It permits the supplied sample datasets and external public
datasets, encourages exploratory analysis and reproducibility, and mentions
free GPU resources.

The stated judging dimensions are:

- model performance
- innovation
- explainability
- code quality and reproducibility
- presentation and storytelling

CardioTrust addresses these with repeated out-of-fold comparison, calibrated
probabilities, a locked holdout, selective prediction, subgroup and error
audits, reproducible artifacts, and a non-diagnostic demo. External validation
remains absent and is not claimed.

The packet does not resolve the upstream dataset redistribution license or the
conflict between the currently visible Devpost deadline and the deadline
previously shown in the joined Kaggle account.
